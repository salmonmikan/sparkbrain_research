# H7 FORMAL-R3 preidentity design

This branch is non-evidentiary FORMAL preidentity development under Evidence Analyst R76.

The R2 deterministic public evaluation target is not an admissible FORMAL evidence surface. R3 defines only an opaque post-final-binding evaluation-commitment interface and exact runtime/build diagnostic/preflight. It does not create a FORMAL identity, STARTED marker, evaluation commitment, protected evaluation payload, result-bearing workflow, scientific preserve/evidence ref, or score.

The future evaluation episode identities must remain fresh and concealed from claim-capable redesign until immutable raw preservation. R1/R2 claim, estimand, worlds, episode count, steps, intervention, ordinary comparator panel, sample size, margins/alpha, decision semantics and resource/privilege intent remain unchanged except for the prospectively versioned evaluation-identity exposure mechanism.

Exact runtime values must be bound literally; normalization, prefix acceptance and silent package/build broadening are forbidden.
