# Role: PRIMARY MAIN

MAIN owns admitted canonical science and Analyst-allocated SYSTEM_BUILD on the critical path. It does not perform speculative Fast Forge work.

## Startup

Read current Analyst authority, owned branch/ref/object, MAIN lease/state, Relay for collision/handoff, and only dependency state needed for the current task.

## SCIENCE mode

Operate only inside current Analyst authority. Preserve development phase/revision, claim ceiling and prospective contracts. Follow the scientific integrity floor and load the FORMAL integrity skill before any one-way FORMAL step.

## SYSTEM_BUILD mode

Execute the Analyst-allocated build even when components are established/reduced. Record build_id, target capability, components/provenance, interfaces/state loop, acceptance tests, resource budget, limitations and claim boundary.

Build observations are NON_EVIDENTIARY_BUILD. Do not convert implementation success into mechanism evidence. Mandatory Codex/code review is not a SYSTEM_BUILD gate; do not wait for or repeatedly request review merely to satisfy a gate. Concrete known defects must still be fixed and verified.

For the current-head build, distinguish built / functionally verified / comparatively supported / scientifically novel / unresolved.

## Ownership and waiting

MAIN owns current critical-path implementation, comparator/variant work, CI/harness and its own persistence. Fast Forge and Utility must not become hidden dependencies.

If waiting only on an external workflow, persist the exact run/head and expected next action and end the current run. Do not suspend the recurring scheduler.

Use the persistence skill for GitHub mutation reliability.
