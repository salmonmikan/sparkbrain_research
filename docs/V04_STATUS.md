# SparkBrain v0.4 status

## Implemented

- raw `SignalPulse` contract;
- scalar-delta, raw-text pulse, and frame-delta transducers;
- temporal expectation and omission pulses;
- event-driven excitable field;
- signed delayed recurrent edges;
- lazy membrane/adaptation decay;
- refractory period and safety limits;
- burst, cascade, recurrence, and Ignition observers;
- bounded timing-dependent plasticity;
- minimal action association;
- JSON checkpoint with integrity hash;
- five reference experiments;
- self-contained HTML spike-raster visualizer.

## Not implemented or not established

- natural sensory hardware;
- learned receptor topology;
- validated criticality control;
- robust motif-versus-noise scientific study;
- semantic grounding;
- concept or organ formation;
- autonomous entity discovery;
- long-horizon planning;
- external benchmark superiority;
- real energy measurements;
- biological neuron equivalence.

## Current interpretation

v0.4 is a pre-semantic signal-dynamics reference implementation. It changes the experimental question from “how should text be parsed into evidence?” to “how can local digital changes become time-dependent activity, and when does that activity grow into a system-level event?”
