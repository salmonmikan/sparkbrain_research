# SparkBrain v0.6 Claim Boundaries

## 1. Protocol status

Two amendments are normative:

1. Protocol Amendment 001 moved missing-middle from the programme centre to one validity assay and
   re-centred v0.6 on internally originated Sparks with causal downstream function.
2. Protocol Amendment 002 states that prediction, action, memory, reward, role, and meaning are
   observer projections rather than Primary runtime relation types.

Both were adopted before confirmatory Level-2/Level-3 evaluation. Earlier plans remain in Git
history.

## 2. Permitted from the implemented engineering foundation

- external and endogenous provenance is explicit;
- internal events do not count as observations;
- positive local learning commit requires registered external consistency;
- an Assembly-free Primary runtime schema exists;
- observers receive immutable traces;
- observer ON/OFF equality can be tested;
- G0 queue-drain continuation is a negative diagnostic;
- G1 anonymous local temporal expectation is implemented;
- G2 externally gated sparse local transition adaptation is implemented;
- registered proposals can enter the normal Field path through bounded reinjection;
- external reality can match, contradict, expire, and cancel stale branches;
- a single-world non-copy, history-dependent, normally thresholded Field-Spark engineering candidate
  exists;
- development checkpoints fail closed on content tampering.

## 3. Evidence levels

### L1 — Endogenous origin

A normally thresholded internal Spark occurred without direct external supply at its target/time.
This does not yet exclude every noise, echo, or engineering shortcut across multiple worlds.

### L2 — Causally participating endogenous Spark

The Spark changes a later anonymous internal state, endogenous event, boundary event, or external
event stream under targeted intervention beyond matched random and sham controls.

### L3 — Externally stabilized relational endogenous Spark

The Spark or lineage participates in a stable, externally confirmable and revisable pattern of
anonymous causal relations across held-out conditions without a predeclared functional relation type.

L1 must not be reported as L2. L2 must not be reported as L3.

## 4. Observer terms requiring strict qualification

### Predictive

Permitted only when the endogenous lineage precedes a later event, improves future estimation, and
loses that advantage under causal suppression beyond matched controls.

### Action-related

Permitted only as an observer description of changed anonymous outbound boundary events and changed
world streams. The runtime must not contain an action type or correct-action target.

### Memory-related

Permitted only as an observer description of a delayed persistent effect supported by reset,
transplant, and matched controls. The runtime must not contain a memory relation type.

### Reward or value

Not permitted for the Primary v0.6 runtime. Reward-driven systems may be reported only as isolated
comparators.

### Functional meaning candidate

May be used only after L3, and only as:

> A post-hoc stable causal relation signature among anonymous internal events, state changes,
> boundary events, external events, and external revision. It does not establish human, subjective,
> linguistic, or semantic meaning.

## 5. Not yet permitted

- multi-world confirmatory L1 evidence;
- autonomous endogenous Spark chains;
- untyped causal downstream participation;
- anonymous boundary coupling with held-out causal value;
- externally stabilized anonymous relations;
- relation revision after world change;
- taxonomy-independent full functionality;
- physical-trajectory functional equivalence;
- confirmatory forward missing-middle validity;
- a resolved persistence locus beyond explicit local transition state;
- a causally functional Field-embedded temporal model;
- semantic understanding, concept formation, value formation, organs, consciousness, AGI, or
  biological equivalence.

## 6. Maximum future expression

Only after amended Gates A–H pass may the project use:

> Under controlled pre-semantic conditions, a persistent Dynamic Field generated endogenous Sparks
> not directly supplied by current input. Without explicit Assembly or predeclared prediction,
> action, memory, reward, role, or meaning types in runtime, those Sparks causally altered later
> anonymous Field or boundary states, and externally stabilized relation patterns remained
> correctable across held-out conditions.

Short form:

> Support for taxonomy-independent, causally participating, externally correctable endogenous Spark
> relations under controlled pre-semantic conditions.

## 7. Prohibited descriptions

- the Spark understood its meaning;
- the runtime discovered a prediction/action/memory/reward type;
- semantic understanding;
- concept formation;
- autonomous value or goal formation;
- imagination or dreaming;
- consciousness or self-consciousness;
- AGI;
- biological-neuron or brain equivalence;
- organ formation;
- proven physical energy efficiency;
- Assembly or typed function heads as the Primary runtime mechanism.

## 8. Taxonomy-independence claim boundary

A functional observer view is valid only if renaming, deleting, or permuting evaluator categories
leaves the runtime Field trace, boundary events, local updates, RNG state, state hash, and checkpoint
continuation unchanged.

If the runtime changes when an evaluator changes what it calls prediction, action, memory, or reward,
Gate A fails.

## 9. Missing-middle claim boundary

A forward missing-middle result requires:

```text
created_at(C_endogenous) < arrival_at(D_external)
```

A correct result supports one temporal validity assay. It does not by itself establish L2, L3,
functional meaning, or the complete v0.6 claim.
