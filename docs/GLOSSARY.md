# SparkBrain Glossary

| Term | Working definition | Not implied |
|---|---|---|
| Spark | local functional state/activity unit | one biological neuron |
| Organ | designed or emergent functional Spark group | anatomical brain organ |
| Belief | persistent task-level hypothesis state | subjective conviction |
| Evidence | externally identified observation record | guaranteed independent fact |
| Support | positive signed relation from evidence to belief | causal truth by itself |
| Contradiction | negative signed external evidence relation | internal inhibition |
| Coalition | temporary hypothesis-centered evidence/state subgraph | permanent module |
| Ignition | gate event that admits a Coalition to Workspace | consciousness |
| Global Workspace | capacity-limited broadcast state | a homunculus or central executive |
| No-ignition | no Coalition currently satisfies the gate | software crash or textual “unknown” |
| Residual loser | nonwinning belief with retained nonzero state | a correct belief |
| Winner-take-most | competition that suppresses but does not always erase alternatives | hard WTA |
| Event routed | only event targets and propagated neighbors are explicitly updated | guaranteed hardware sparsity |
| Lazy decay | compute decay when state is touched rather than every tick | no passage of model time |
| Trace | recorded engine state and causal path at observation points | complete proof of interpretation |
| Functional mimicry | reproduction of selected cognitive behavior | biological fidelity |
| Computational-principle mimicry | use of sparse/event/recurrent/excitatory-inhibitory principles | neural equivalence |
| Spiking equivalence | predefined behavior preserved within tolerance on a spiking backend | human-like cognition |
