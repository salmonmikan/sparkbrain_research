# v0.6.1 D9 — SparkBrain Hypothesis Discrimination Matrix

## 1. Purpose

Candidate-003 and the subsequent observer-only diagnostics identify several mechanisms that can
produce the observed failures. This document prevents one attractive explanation from being adopted
prematurely.

The unit of analysis is not “which change raises the pass rate?” It is:

> Which hypothesis explains the existing evidence, what would falsify it, and does it preserve the
> SparkBrain research boundary?

No Primary runtime change is made here.

## 3. Competing hypotheses

### H1 — Missing anonymous causal-credit circulation

External relation evidence is stored, but does not return to the earlier local temporal lineage that
caused the boundary interaction.

| Evidence | Relation to H1 |
|---|---|
| E2 | explained: local temporal score dominates without later functional evidence |
| E3 | directly predicted |
| E4/E5 | compatible: two explicit state loci remain separate |
| E6/E7 | compatible: downstream expression cannot repair upstream competition |
| E8 | compatible: explicit comparators bypass or partition the missing circulation |

**Current assessment:** strongest integrative explanation, but not demonstrated as a working
SparkBrain mechanism.

**Falsifier:** show that world-confirmed anonymous evidence already changes later shared-root G1
competition when local observations are held fixed.

**Main risk:** an eligibility/credit table may merely become another explicit transition predictor.

### H2 — Distributed Field memory exists but is poorly calibrated

Experience is already distributed in Field membrane, adaptation, or persistent traces; thresholds or
gain simply prevent reliable expression.

| Evidence | Relation to H2 |
|---|---|
| E4 | against: G1 state transfers the chain while matched Field state does not |
| E5 | against: consistency state transfers re-entry while matched Field state does not |
| E6 | partially compatible with expression bottleneck |
| E2/E3 | not explained by Field memory alone |

**Current assessment:** unsupported for the demonstrated long-lived experience effects. Short-term
Field residual integration remains real, but it is not evidence of distributed learned memory.

**Falsifier:** already partly falsified for the canonical transfer conditions. A stronger version
would require independent transfer of functional bias with Field-side state alone.

### H3 — The primary defect is threshold/gain calibration

The architecture is correct; a different threshold, variance scale, or re-entry gain would remove
the failures.

| Evidence | Relation to H3 |
|---|---|
| E6 | can change abstention versus expression |
| E7 | worsening risk: more gain can increase superposition |
| E2/E3 | not explained: calibration does not introduce world relevance into G1 |
| E9 | cannot create a missing causal baseline without changing the mechanism under test |

**Current assessment:** rejected as a sufficient explanation. Calibration changes may alter symptoms
but do not close the missing causal path.

### H4 — The negative result is only an evaluator/ontology mismatch

Dual trajectories and multiple relation outputs may represent uncertainty rather than failure; the
singleton evaluator is too strict.

| Evidence | Relation to H4 |
|---|---|
| E7/E10 | supportive: coexistence can be meaningful under ambiguity |
| L-A class | supportive: main trajectory remains present and selectively removable |
| L-B/C0 classes | against: world-facing trajectory or later expression is absent, not merely plural |
| minimum-family result | not erased by reinterpreting only plural-output cells |

**Current assessment:** partially valid. Some frozen failures conflate bounded plurality with error,
but evaluator mismatch cannot explain the complete negative result.

**Required diagnostic:** follow each coexisting candidate into later external evidence and test
whether the system itself differentiates them without evaluator-provided labels.

## 5. Pre-implementation discriminator programme

### P1 — Causal lineage versus matched correlation

Present two matched local lineages with the same event count, timing, and energy. Only one lineage
actually produces an externally returned anonymous relation.

A candidate credit process must later alter the causally responsible lineage more than the matched
correlated lineage.

### P2 — Fixed local evidence, reversed world relation

Freeze G1 transition observations. Reverse only the anonymous world consequence across episodes.

```text
future G1 competition changes
    -> evidence for B-to-A circulation

only final re-entry changes
    -> current downstream-only loop remains
```

### P3 — State-locus cross transplant

Cross four components independently:

```text
local transition state
Field membrane/adaptation/trace state
anonymous consistency state
transient re-entry state
```

Measure whether success, overgeneration, alternate-only selection, or abstention follows each
component.

### P4 — Ambiguity resolution through later evidence

Allow two genuinely co-maximal trajectories. Do not demand an early singleton. Later, provide raw
external evidence that differentiates their consequences.

A useful SparkBrain mechanism should preserve bounded alternatives initially and then alter later
competition through externally evidenced causal history.

### P5 — Table-equivalence audit

For any proposed anonymous eligibility or credit mechanism, construct the smallest equivalent
explicit transition/lookup table. If the new mechanism is behaviorally and structurally equivalent
to that table, report it as explicit memory rather than emergent Field organization.

## 6. Decision boundary for future work

A future mechanism is not accepted merely because it improves lag-dispersion or contingency-cycle
scores. It must show all of the following:

```text
causal-lineage selectivity
external-confirmation-only update
reversal and contradiction correction
future shared-root competition change
bounded ambiguity
no evaluator target, reward, semantic role, or Assembly runtime key
reset/transplant falsifiability
non-equivalence to a hidden explicit predictor, or honest reporting that it is one
```

## 7. Current theoretical conclusion

Candidate-003 does not justify abandoning endogenous Spark research, but it does reject a stronger
claim: local temporal regularity, Field execution, and anonymous external consistency do not become
one functional process merely because they are connected in a forward loop.

The next SparkBrain question is therefore not:

> How can the current model pass more tests?

It is:

> Can externally evidenced consequences circulate backward through anonymous causal lineage and
> reorganize future local trajectory competition without becoming a typed reward system, an
> Assembly-keyed model, or an explicit sequence predictor under another name?
