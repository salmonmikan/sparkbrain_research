# SparkBrain Research Versions

This directory contains architectural research tracks that are intentionally separated from numbered SparkBrain versions.

## Active track

- `RV01 — Endogenous Transition Substrate`
  - Working branch: `research/rv01-endogenous-transition`
  - Frozen baseline: `archive/v06-pre-rv01`
  - Master plan: `docs/research/RV01_MASTER_PLAN.md`

## Policy

Research Versions are used when a foundational runtime assumption is under direct falsification or replacement.

They are not aliases for semantic version increments. In particular, RV01 is **not** `v0.7`.

Numbered architecture versions should resume only after the relevant research track stabilizes sufficiently to justify a new integration baseline.
