## Decision and purpose

After real joint-ownership G0 and the checkpoint prerequisites below, the smallest useful
next experiment is a two-consumer path pilot: acquired native history features S and a
strong, task-specific raw-order representation R. One exposed 64-window acquisition,
two teaching windows and two independent native queries require **68 producer calls**.
Crossed inlet and sham controls reuse those query exports.

The question is whether the real M1 uses the supplied temporal feature path, and what
prediction, routing and action each implementation produces on this bounded pair.
Native superiority is not an acceptance condition. The raw code is sufficient information
for the deterministic two-order task, but its implemented M1 consumer must still reach
valid correct actions through finite teaching, confidence, routing and runtime gates.
Conditional on R doing so, there is no remaining action-accuracy headroom.

Two query points establish neither statistical noninferiority nor generalization.
There is no frozen-weight acquisition arm, so no weight-learning-necessity claim.
The larger 384-call S/F0/R proposal and a weight-donor factorial are deferred, not part
of this pilot. The earlier 192-call proposal was prequential; this document does not
relabel it as a historical held-out result.

## Arm and information contract

**S/native:** reuse the exposed PR182 acquisition recipe without a favorable seed or
checkpoint search. Acquire with native assembly/weight/delay/homeostatic learning;
disable prediction, action and reward modulation. After the prefix freeze assembly
and field/homeostatic learning as in PR182. Receptor, membrane, queue and other ordinary
transient state still evolve. Never call the producer's outcome-learning method.

Retain every mature native canonical coordinate, unchanged native similarity and
the prospective PR182 tie/collision rules. Require a nonempty dictionary of at most
seven coordinates; pad only the unused tail with zeros. Missing dictionary, too many
coordinates, native ties and binding failures are distinct ineligibility outcomes.
Do not truncate, change similarity scale, add counters/drive/epsilon, or extend acquisition.

**R/raw:** a fixed, engineered input-order reduction, not a learned assembly or a PSR.
It has access to the same observed causal pulse/history records but deliberately uses
only the current window's A/C order. Its seven-coordinate output is defined below.

Start two fresh, independent real M1 owners. Both receive the same original current
sensory scalar and original route coordinate, held constant across the pair, plus their
arm's seven temporal coordinates in **both** inlets. Freeze identical M1 configuration,
hypothesis/router limits, channel schema, outcome schedule and cutoff. Check actual
injected dimensional limits before mutation: the eight-dimensional routing ceiling
allows one original coordinate plus seven temporal coordinates, while the router still
has exactly two components. Wider vectors do not grant more scopes.

This is equal causal input access and consumer headroom, not equal retained information
or matched total parameter/computation cost. Record actual native dictionary size,
producer state, raw history, M1 state, copies, bytes and work. Do not give R a fragile
three-or-more-cluster encoder just to make its two-scope consumer fail.

### Exact raw encoder domain

Inspect the declared window `[start_ms, start_ms + 40 ms]`, inclusive. Require exactly
one channel-A pulse and exactly one channel-C pulse. Each must have finite positive
magnitude and polarity `+1`. All supplied window pulses must meet the common causal
contract; future or malformed input rejects before either component advances.

| Observed cue condition | R result |
|---|---|
| `t_A < t_C` | `(1,0,0,0,0,0,0)` |
| `t_C < t_A` | `(0,1,0,0,0,0,0)` |
| `t_A == t_C` exactly | `ambiguous_order`, no accepted vector |
| Missing/multiple A or C; zero cue magnitude; negative cue polarity | `out_of_domain`, no accepted vector |

Count all A/C pulses; do not silently discard extras or choose their first/last event.
Use no epsilon, tolerance, label, regime, ID or dictionary binding to resolve order.
Slot meaning is fixed before teaching and does not encode alpha/beta outcomes.
F/Q and nuisance pulses remain retained but are intentionally ignored by this encoder.

This reduction is sufficient only for a declared target depending on A/C order,
independent of the ignored details. It is not sufficient for missing/tied/multiple
cues, polarity-dependent meanings, different target semantics or longer-history tasks.
If the literal proposal has such cases, revise this design **before** execution.
Preserve the full raw pulse records and inherited raster construction for inspection.

## Proposed schedule and consumer controls

1. Run one 64-window exposed native acquisition. Preserve the complete acquired graph,
   dictionary and counters before interpreting eligibility.
2. Teach each M1 with one A window and one B window in the same frozen order, using
   opposite signed outcomes of the same frozen magnitude. Current outcomes are
   unavailable until after the corresponding action. Use separate exact receipt IDs
   and the joint candidate/publication discipline for observe and feedback.
3. Preserve each arm's complete post-teaching joint owner. Create separate query
   candidates for A and B from that same owner. Native candidates each advance the
   producer once, retain the actual export, and call real M1. R uses the paired raw
   inputs through its fixed encoder. Pair nuisance, cutoff, original current values,
   event ID and decision time within these independent query branches.
4. From the same trained M1 beforestate, use the preserved accepted A/B exports to
   evaluate all four predictive/routing inlet combinations. The factual A/A and B/B
   cases are already the two primary queries. Add only A/B, B/A and an exact-copy
   A/A sham per arm. No extra producer advance or outcome is allowed.
5. Preserve every query/control output and full graph. On each of the ten total
   query/control branches, perform one explicit native predictive checkpoint save
   and one readback load, preserve compatibility evidence, then dispose resources
   in the approved lifecycle. No evaluation receipt or next observation follows.

The three added controls are **explicit consumer-inlet interventions**, not normal
producer transactions or new evidence. Their cloned producer/raw-history state does
not advance; it must remain unchanged. Compare their M1 beforestate and observation
binding exactly. The future literal freeze must copy factual A/A's exact event ID,
decision time (using the same declared time origin and milliseconds-to-seconds
conversion), original current values and complete adapted observation into its sham;
do not derive a new timestamp from the unadvanced control producer's clock or mint
a control-specific ID visible to M1. Counterfactual labels remain audit-only.
The A/A sham must match factual A/A's complete M1 aftergraph and
outputs, not the entire joint graph: the factual branch has advanced its producer,
whereas the consumer-only control has not. All full joint graphs still undergo
independent type/alias/isolation and original-owner noninterference checks.

Never claim these controls are whole-producer interventions, commit their synthetic
bindings as factual receipts, or require different dictionaries to share coordinate
semantics. Mixed inlets may produce legitimate predictive/scope disagreement-abstention.
Retain prediction, predictive choice, route choice, final action and reason separately.

The evaluator alone keeps the two query targets. Since M1 requires feedback before a
second observation, independent clones avoid teaching on query outcomes. Do not clear
pending state by hand. These two exposed development queries are not an unseen-state
or statistically held-out generalization study.

## Measurements, negative outcomes and stopping

Preserve raw actions and graph evidence before scoring. Report each of the two
primary query decisions, prediction scalar, scope decision, abstention/rejection
reason and signed-outcome prediction error where a prediction exists. Do not turn
M1's arbitrary signed scalar into an unregistered probability/Brier score.
Coverage denominators are the planned two primary queries per arm, with missing and
invalid results identified separately; control branches are not extra accuracy samples.

| Finding | Allowed interpretation |
|---|---|
| Accepted native vectors differ | Representation prerequisite only |
| Inlet interventions change prediction or routing but not action | Narrow path effect at the changed endpoint |
| Final action changes with exact sham equality | Bounded consumer-inlet contribution |
| Native and raw both give correct actions | Operational side-by-side success; no native superiority |
| Native differs but raw suffices equally | Ordinary-history reduction remains adequate |
| Valid abstention | Legitimate result with its reason; never force a decision |
| Identical vector with opposite teaching sign | Aliasing/receipt incompatibility, not wrong-answer accuracy |
| Width/scope capacity, no dictionary, native tie | Explicit representation/consumer incompatibility |
| Unsupported type, checkpoint failure, sham drift, owner mutation or cleanup failure | Invalid/blocked path; stop affected work and retain evidence |

A terminal integrity/resource/evidence-write failure stops the run. Ordinary arm-specific
ineligibility stops its dependent work; the other arm may finish only its already declared
independent schedule. Never replace a failed arm, use a fresh receipt ID to bypass conflict,
rescore unavailable predictions as wrong answers, or call partial coverage noninferiority.
Stop at the frozen schedule or an earlier declared failure, with no seed/threshold/budget
rescue or favorable-result continuation.

A valid negative/inconclusive result is an acceptable output. Even a positive path result
would not identify acquisition-time weight necessity, physical-unit/assembly causality,
novelty, energy efficiency, statistical noninferiority, unseen states or generalized learning.
No F0 inference may be borrowed from historical retention data.

## Original-paper constraints and publication boundary

[Maass, Natschläger and Markram (2002)](https://igi-web.tugraz.at/people/maass/psfiles/130.pdf)
separate internal trajectory separation from readout approximation; export differences
alone therefore do not establish useful downstream behavior.
[McCallum (1994)](https://proceedings.neurips.cc/paper/1994/file/d2ed45a52bc0edfa11c2064e9edee8bf-Paper.pdf)
provides ordinary history-based state-disambiguation precedent, motivating a serious
raw-history reduction rather than a deliberately aliased current-only control.
[Littman, Sutton and Singh (2001)](https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf)
define predictive state through future-test sufficiency; this two-order wire pilot
neither implements PSRs nor inherits that sufficiency guarantee.
