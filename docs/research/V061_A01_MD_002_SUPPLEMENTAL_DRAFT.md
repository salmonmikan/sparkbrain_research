## P2: change the world, not the credited path

Both world arms receive identical pre-intervention local temporal state, causal
support state, anonymous relation history, paired A/B proposal schedule, boundary
schedule, ports and admissible observation budgets. Establish the same unique
anonymous prior target x first.

Only the world response mapping changes:

- W0: boundary produced by A yields x; boundary produced by B yields y.
- W1: boundary produced by A yields y; boundary produced by B yields x.

The world fixture, not the evaluator or bridge, generates actual external
responses and parent IDs. Both A/B events occur in both arms. Do not pass an
arm-specific credited path directly into the bridge as the intervention.
Distinct mapping-content hashes, not distinct relation labels, must establish
that W changed.

Use matched cloned attribution subepisodes per path, each beginning from the
same pre-observation C prior, so response-order-induced C adaptation cannot
silently confound the map effect. Their admissible local support updates are
then compared at a common subsequent shared-root probe. The exact reset/restore
boundary and state-combination semantics must be bound before execution; no
post-result adjustment is permitted.

Alternatively a continuous schedule may be bound only after a source-level
proof that ordering and prior adaptation cannot explain the arm difference.
These are alternatives to resolve before freeze, not selectable after results.

Evidence-withheld counterparts keep the respective world maps but suppress
returned external evidence. They must not differentiate support or competition.

Success: changed world mapping yields the prescribed opposite local support
and subsequent competition differences under matched initial state and schedule.
Failure/invalidity: only labels or final re-entry differ; causal ancestry differs
before intervention; C history differs undeclared; evidence-withheld controls
differentiate; or no later local competition effect occurs.

## P3: execute a real transplanted third state

Capture a complete serializable runtime snapshot immediately before external
attribution. Declare precisely which ledger/proposal and pending-boundary
references belong to R. C learned statistics, L learned state and F physical
state are separate from that routing slice. Hash every included and excluded
component; a handwritten surrogate hash is not a state capture.

For each direction, construct baseline, donor and a third actual transplanted
runtime. Clone the baseline, transplant only the declared donor R slice with
consistent references, and execute the same independently generated external
observation. Capture pre- and post-execution state and competition.

Pre-intervention non-R hashes must match baseline exactly. After attribution,
an L update is expected and must be measured, not hidden behind pre-update L
hashes. The third arm's outcome must come from its own execution; donor outcome
substitution is prohibited.

Both directions test A-to-B and B-to-A routing. R necessity should additionally
be checked through an execution-bound negative/control fixture before final
matrix freeze; whether this adds rows must be declared at that freeze.

Stop if full-state cloning or R-only partition cannot be implemented faithfully.
Do not claim a full F transplant from changing an origin-state tag. The F
interface-only question and a genuine physical F intervention are distinct.

## P4: retained plurality and later differentiation

Generate separate and genuinely merged BoundaryEvent ancestries. Record actual
runtime-active proposals and bounded continuation traces; active lineage lists
cannot be supplied as expected constants.

Merged confirmation may validly update the entire actual ancestry. It must not
be scored as successful selective differentiation merely because both paths
remain active. Test later evidence that separates causal contributions and
later evidence that remains inseparable.

For inseparable ancestry, preserved ambiguity/abstention is a valid recorded
behavior but not automatic success on a task requiring useful differentiation.
Report that condition's registered failure if the required differentiation is
not achieved. No forced singleton or identifier tie-break may repair it.

Absence and replay controls must preserve the appropriate unchanged support.
Separate event branches establish that differentiation is possible when causal
evidence genuinely distinguishes the paths.

## P5: N1 and a genuine recurrent N3

N1 is the explicit local support-table null, with shared admissible exact-parent
provenance and anonymous classification as allowed by the original protocol.

N3 must be a separately bound resource-matched recurrent causal-trace model with
actual elapsed-step recurrence. Renaming N1's counters as a hidden recurrent
state is not adequate comparator-family coverage. Before execution, bind:

- state/update equations, topology, fixed weights or learning rule and decay;
- causal eligibility input and anonymous-evidence interface;
- readout and training/development selection procedure;
- parameter, persistent/transient byte, update/lookup and step budgets;
- comparator code SHA, source manifest, initialization and seed policy;
- no direct evaluator-target access and no access to candidate output.

Use only separately declared development material for any comparator selection.
MD-001 or MD-002 outcomes cannot tune N3. If no genuine compatible N3 exists,
retain **DRAFT_N3_UNBOUND** and do not execute or claim complete P5.

Instrument actual per-arm state writes, local/global lookups, transient peak
occupancy, persistent serialization bytes and observation-to-effect latency.
Separate common infrastructure costs from incremental mechanism costs.
Measurements cannot be copied between arms, inferred from challenge names or
replaced by shared constants. Verify observation does not alter dynamics.

Compare complete time-indexed traces and state interventions as well as outputs.
Resource mismatch means an unmatched comparison, not an accepted matched null.
N1 reduction may be reported separately even if N3 differs. Falsifying one
comparator never establishes Field emergence.

Identifier permutation must be a bijection of all declared relevant identifiers.
Physical-trajectory substitution must alter actual executed trajectory under
matched causal relationships, not only a metadata label. Unseen combinations
must be withheld under a fixed definition, not selected after observation.
