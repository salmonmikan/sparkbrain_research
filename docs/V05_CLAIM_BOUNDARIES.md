# SparkBrain v0.5 claim boundaries

## Permitted engineering claims

- multi-timescale local receptor state is implemented;
- bounded homeostatic threshold adaptation is implemented;
- weight and delay learning can be independently ablated;
- unlabeled Cascade observations can be clustered into Assembly Candidates;
- prediction, action, and intervention contracts can be tested locally.

## Claims requiring evidence gates

- selective temporal Assembly: Gate A+B;
- reusable temporal Assembly: Gate A+B+C;
- functional temporal Assembly: Gate A+B+C+D;
- causal functional temporal Assembly: Gate A+B+C+D+E.

## Prohibited interpretations

v0.5 must not be described as semantic understanding, concept formation, organ formation, consciousness, AGI, biological equivalence, or proven energy efficiency. Evaluator motif IDs and answer labels must not enter runtime state.
