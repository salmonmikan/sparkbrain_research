# SparkBrain v0.6 Protocol Amendment 003
## Relation Re-entry, Persistence Falsification, and Confirmatory Generalization

**Status:** normative after Protocol Amendments 001 and 002  
**Adopted:** before V06-12A confirmatory execution  
**Branch:** `v06`

## 1. Why this amendment is required

V06-08 through V06-11 produced increasingly strong single-world engineering candidates:

- a history-dependent endogenous Field Spark;
- a sequential endogenous chain under external silence;
- a selective anonymous outbound-boundary effect;
- an externally stabilized, reversed, and reacquired anonymous relation state.

However, V06-11 revises a relation record without yet proving that the revised relation changes a
future Field trajectory or future boundary event. The current loop ends at:

```text
Field -> World -> anonymous relation state
```

The required SparkBrain loop is:

```text
Field -> World -> anonymous relation state -> later Field Dynamics
```

A second gap is that all Level-1 through Level-3 results remain single-world engineering candidates.
The current plan did not provide an independent, code-frozen multi-world and multi-seed confirmatory
stage before release.

This amendment closes both gaps and changes the remaining work order.

## 2. Revised remaining work order

## 3. V06-12A — Relation Re-entry

### Research question

Can an externally stabilized anonymous relation alter a later anonymous Field trajectory and later
boundary event without a reward, correct action, functional role, semantic label, or typed head?

### Minimal mechanism

No new learned state family may be introduced. Re-entry must derive a transient generic influence
from the existing anonymous consistency state:

```text
existing anonymous consistency state
        ↓
derived anonymous support
        ↓
ordinary bounded Field current / local influence
        ↓
normal membrane, threshold, refractory, inhibition, and adaptation
        ↓
later anonymous Spark and boundary event
```

The re-entry adapter may contain static structural configuration and execution records. It must not
contain a second learned relation table.

### Required causal evidence

With identical current input and identical initial Field state:

1. an acquisition-state runtime and a reversal-state runtime produce different later Field or
   boundary traces;
2. resetting anonymous consistency state removes the difference;
3. transplanting the consistency state transfers the difference to a naive compatible runtime;
4. suppressing the re-entry path removes the difference while matched-random suppression does not;
5. internal-only recurrence cannot create or strengthen the re-entry support;
6. no typed prediction/action/memory/reward field is introduced.

### Interpretation

If relation state changes only an observer report and not later Dynamics, Gate G remains failed.
If a newly added hand-authored state machine, reward, or correct-action target is required, the
Primary hypothesis is not supported by that implementation.

## 4. V06-13 — Persistence locus as a falsification experiment

V06-13 is not a memory feature-development stage. It asks what the current system actually is.

### Candidate state components

- Field membrane and residual state;
- threshold and adaptation state;
- persistent traces;
- G1 local transition statistics;
- G2 local path calibration;
- pending eligibility;
- pending endogenous queue;
- anonymous boundary-consistency state;
- static boundary/world wiring;
- derived re-entry influence, which must have no persistent state of its own.

### Reset tests

Reset exactly one component after experience and compare the complete later anonymous runtime trace.

### Transplant tests

Move exactly one compatible component from a trained runtime into a naive runtime and test whether
experience-dependent behaviour transfers.

### Required interpretations

- If resetting G1/G2 state removes all history-dependent behaviour and no Field-side component
  carries or transfers it, report that v0.6 is effectively a Dynamic Field plus explicit local
  transition memory.
- If consistency-state transplant alone transfers relation-dependent re-entry, report that external
  relation persistence is localized there.
- If multiple components are jointly necessary and no one component is sufficient, report a
  distributed interaction rather than inventing a memory organ.
- If Field/adaptation/trace reset or transplant carries independent experience effects, treat that as
  a stronger distributed-dynamics candidate.

Negative and limiting results are first-class outcomes.

## 5. V06-12B — Validity assays

After re-entry and persistence-locus work, run:

- forward missing-middle;
- prefix continuation;
- branching futures;
- omission controls;
- retrospective reconstruction;
- external contradiction;
- temporal-rule reversal.

Missing-middle forward success still requires:

```text
created_at(C_endogenous) < arrival_at(D_external)
```

These assays diagnose internal-model-like properties. They do not define SparkBrain success by
themselves.

## 6. V06-13.5 — Confirmatory Generalization Suite

### Code freeze

Before confirmatory worlds are generated:

- freeze Primary runtime code;
- freeze evaluator code;
- freeze metrics and thresholds;
- freeze world-generator families and seed ranges;
- publish hashes of the frozen configuration;
- prohibit tuning on confirmatory results.

### World families

At minimum include held-out variations in:

- anonymous unit and port permutations;
- chain length and branch factor;
- lag, magnitude, polarity, and threshold bands;
- distractor and noise density;
- external relation target and reversal timing;
- partial observation and omitted events;
- compatible state-transplant mappings.

### Seeds

Each world family must be evaluated over multiple frozen seeds. Development seeds and confirmatory
seeds must be disjoint.

### Required Primary sequence

For each applicable world/seed:

```text
endogenous origin
    ↓
causal internal continuation
    ↓
anonymous boundary effect
    ↓
external relation stabilization
    ↓
relation re-entry changes later Dynamics
    ↓
world reversal
    ↓
relation revision and later-Dynamics change
    ↓
reacquisition
```

### Matched controls

- no-endogenous;
- random-endogenous;
- queue/readout-only;
- no-reentry;
- shuffled relation state;
- matched-random intervention;
- sham intervention;
- G3 generic recurrent predictor;
- G4 explicit Assembly-conditioned predictor;
- G5 typed prediction/action/memory/reward-head comparator.

G3, G4, and G5 remain isolated from the Primary import graph.

### Confirmatory status

No Level-1, Level-2, or Level-3 claim may be promoted from engineering candidate to confirmatory
support until this suite is complete. Failure of a Primary route with comparator success is a valid
negative result and must be reported as such.

## 7. V06-14 — Release gate

V06-14 may begin visualization work earlier, but release review occurs only after V06-12A, V06-13,
V06-12B, and V06-13.5 are complete or a formally documented negative-completion decision is made.

Required final audit:

- Observer/evaluator present versus absent equality;
- taxonomy rename and permutation equality;
- source/config/checkpoint/trace forbidden-field scans;
- local deterministic reproduction;
- raw negative artifacts;
- strongest counterexample report;
- comparator isolation;
- runtime ontology and evaluator-taxonomy inventories;
- no hidden reward, answer, correct-action, Assembly, or typed functional relation.

## 8. State-proliferation prohibition

From this amendment onward, a new persistent runtime state family requires a written justification
showing that the experiment cannot be performed with existing Field, transition, eligibility,
queue, consistency, or boundary state.

The default decision is **do not add state**.

Relation re-entry must be a derived use of existing consistency state. Persistence-locus experiments
must inspect existing state rather than create a new memory module. Validity and confirmatory suites
must not introduce task-specific answer machinery.

## 9. Gate status after this amendment

- Gates for engineering provenance, non-copy origin, causal chain, boundary effect, stabilization, and
  revision have single-world candidates.
- Gate G remains open because revised relation state has not yet changed later Dynamics.
- The persistence locus remains unresolved.
- Generalization remains unconfirmed.
- Release remains blocked.

## 10. Maximum permitted statement before completion

> v0.6 currently contains single-world engineering candidates for endogenous origin, causal internal
> continuation, anonymous world coupling, and externally revised anonymous relation state. It has
> not yet shown that revised relation state re-enters future Dynamics, where the experience is
> physically carried, or whether the result generalizes across held-out worlds and seeds.
