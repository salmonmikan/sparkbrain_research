## Current mechanistic picture

```text
anonymous local transition evidence
    -> G1 frequency × temporal-stability score
    -> shared-root trajectory expression
    -> Field integration and threshold
    -> outbound BoundaryEvent
       [Spark/proposal/unit lineage still present]
    -> PendingBoundaryExposure / AnonymousLinkState
       [historical proposal/path return address compressed away]
    -> anonymous relation reliability
    -> relation re-entry
    -> later Field Spark
```

Two distinct gaps are now supported.

### Gap 1 — No relation-to-G1 dependency

Anonymous consistency and relation re-entry do not call or update the G1 local transition-learning
path. Changing later world relation while local evidence remains fixed therefore cannot reorganize
the earlier trajectory competition.

### Gap 2 — Historical causal return address is lost

Even if a future update call were added, the current stored relation does not identify which
historical local proposal/path lineage produced the externally confirmed boundary event. The system
cannot apply selective external evidence to the original cause after that compression.

The second gap is stronger than a missing function call: the required information is no longer
represented.

## Current strongest SparkBrain diagnosis

> The current Primary forms endogenous activity, local temporal regularity, anonymous world
> consistency, and later relation expression, but these do not form one credit-circulating causal
> process. World evidence is stored downstream after the historical return address to the producing
> local trajectory has been discarded.

This explains why:

- a temporally stable but world-irrelevant branch can win under lag dispersion;
- correct relation storage can fail to become a Field Spark;
- several old/new relations can co-express;
- changing a world relation does not change future G1 competition;
- explicit comparator decompositions remain more robust on the frozen benchmark.

## Implemented fail-closed protocols

### P1 — Causal lineage versus matched correlation

Two anonymous lineages are matched in event count, timing, current, and energy. External evidence
must follow the actual causal lineage after lineage swap; contradiction must selectively weaken that
lineage; absence/internal replay cannot create positive credit.

### P2 — Fixed local state, changed anonymous world relation

Local transition state is held byte-identical while the world relation changes. A future mechanism
must alter later shared-root competition, not only final relation re-entry.

### D11 — Explicit-table equivalence

A surviving mechanism is never declared emergent by static inspection. It must be compared against
the smallest explicit predictor that reproduces its behavior. Persistent lineage-to-target lookup,
Assembly-keyed state, typed heads, scalar reward, and self-confirming updates remain outside the
Primary boundary.
