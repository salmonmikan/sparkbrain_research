## 1. Destination

v0.6 asks whether an already running Dynamic Field can generate an internal Spark not directly
supplied by current external input, use that Spark as causal material for later anonymous Dynamics,
form an externally gated relation, and let the acquired relation alter future Dynamics.

```text
world-to-field event
        ↓
persistent Dynamic Field
        ↓
endogenous Spark X
        ↓
later anonymous Field / boundary event
        ↓
changed external stream
        ↓
external consistency or contradiction
        ↓
existing anonymous relation state changes
        ↓
relation state re-enters normal Field Dynamics
        ↓
future Brain State changes
```

The Primary runtime contains no explicit Assembly and no predeclared Prediction, Action, Memory,
Reward, Role, or Meaning relation type.

```text
immutable runtime trace
        ↓
──────────────── Observer Boundary ────────────────
        ↓
post-hoc trajectory / Assembly / causal-relation analysis
        ↓
optional predictive / boundary-effect / persistence / world-coupling views
```

The central question is:

> Can a persistent Dynamic Field generate endogenous Sparks not directly supplied by current input,
> let them causally alter later anonymous Field states and boundary-crossing events, stabilize and
> revise those relations through external interaction, and feed the learned anonymous relation back
> into later normal-rule Dynamics while all human functional categories remain observer-derived?

Missing-middle completion remains one supporting validity assay. It is not the definition of v0.6.

## 2. Runtime ontology versus observer taxonomy

### 2.1 Primary runtime ontology

The runtime may contain execution-relevant structure only:

- anonymous unit, channel, region, and boundary-port IDs;
- event time, magnitude, polarity, duration, and direction;
- external/endogenous provenance and causal parentage;
- membrane, threshold, refractory, adaptation, residual, and persistent traces;
- anonymous local lag, signed influence, reliability, and external consistency;
- eligibility and bounded generation state;
- anonymous relation re-entry proposals using existing relation state;
- queue, energy, depth, lifetime, and branch budgets.

These values say where, when, how strongly, and through which path something happened. They do not
say what it means.

### 2.2 Observer/evaluator taxonomy

The observer may later ask whether a lineage:

- preceded and improved estimation of a later event;
- changed an anonymous outbound boundary event;
- left a delayed persistent effect;
- changed the later external stream;
- revised after external contradiction;
- transferred under state transplant.

Humans may describe those as predictive, action-related, memory-related, world-coupled, corrective,
or functional effects. Those terms are non-exclusive evaluation views, not runtime classes.

### 2.3 Forbidden reification

The Primary runtime must not contain or infer:

```text
AssemblyState
PredictionRelation
ActionRelation
MemoryRelation
RewardRelation
FunctionalRole
MeaningState
correct_action
scalar_reward
utility_target
outcome_class
goal_label
```

Nor may it add a dedicated prediction, action, memory, reward, goal, or semantic head on the Primary
path.

## 3. Meaning and relation

The runtime must not attach:

```text
spark.meaning = "danger"
spark.semantic_state = "food"
spark.role_type = "prediction"
```

The permitted local structural relation is category-neutral:

\[
U(i,j)=
\left(
source_i,
 target_j,
 \Delta t,
 signed\ influence,
 reliability,
 provenance,
 external\ consistency
\right)
\]

An observer may later estimate:

\[
R_X=
\left\{
X\rightarrow Y_k,
\Delta t_k,
\Delta P(Y_k\mid do(X)),
stability_k,
external\ consistency_k
\right\}
\]

where `Y_k` is an anonymous internal event, state component, boundary event, or external event.

A functional meaning candidate may be discussed only after a stable causal signature is externally
correctable, causally used, and reproduced in held-out conditions. It remains an observer conclusion,
not a runtime field.

## 4. No privileged reward

The Primary v0.6 track receives no scalar reward, punishment, correct action, utility target, or goal
label. The world returns ordinary raw external pulses. Anonymous homeostatic variables may exist only
as ordinary state variables. Reward-driven systems belong to the isolated G5 comparator.

## 5. Boundary events and relation re-entry

### 5.1 Anonymous boundary event

```text
endogenous Field trajectory
        ↓
outbound port:k
        ↓
world transition
        ↓
later raw world-to-field events
```

The runtime is not told that a port is an action or whether its consequence is desirable.

### 5.2 Relation re-entry

Externally gated anonymous relation state must be capable of changing later Dynamics without adding a
new semantic state machine.

Reference mechanism:

```text
existing anonymous link reliability
        ↓
category-free magnitude / confidence
        ↓
EndogenousPulseProposal
        ↓
existing FieldReinjectionGate
        ↓
ordinary membrane / threshold / refractory / adaptation
        ↓
later anonymous Spark or no Spark
```

All eligible links use the same rule. The evaluator does not select a winner. Competition must arise
from existing relation strength and normal Field Dynamics.

A relation that is updated but never changes later Field or boundary behaviour is not a closed
functional loop.

## 6. Persistence instead of a predefined memory type

Experience may alter:

- membrane or residual state;
- threshold or adaptation;
- weight or delay;
- persistent trace;
- G1 local transition state;
- G2 path adaptation or eligibility;
- pending endogenous queue;
- anonymous boundary consistency;
- relation re-entry working state.

An observer may call an effect memory-like only after delay, reset, transplant, and matched controls.
The runtime does not update a `MemoryRelation`.

## 7. Evidence levels

### Level 1 — Endogenous origin

A normally thresholded Field Spark occurs without direct external supply at that target and time.
Noise, fixed echo, queue replay, and evaluator leakage must be excluded.

### Level 2 — Causally Participating Endogenous Spark

The Spark changes a later anonymous internal state, endogenous event, boundary event, or external
stream. Targeted intervention must exceed matched random and sham controls.

### Level 3 — Externally Stabilized, Revisable, and Re-entering Anonymous Relation

The Spark or lineage participates in a stable externally confirmable relation that:

- revises when the world changes;
- changes later normal-rule Field or boundary Dynamics;
- loses that later effect under relation reset or targeted intervention;
- survives held-out conditions;
- remains taxonomy-independent and self-confirmation-safe.

Level 3 is the Primary v0.6 target. It is not semantic understanding.

## 8. Generator and comparator hierarchy

```text
G0  Field-only spontaneous continuation       Primary
G1  local temporal expectation traces         Primary
G2  sparse/local transition adaptation        Primary
G3  generic recurrent predictor               Comparator
G4  explicit Assembly-conditioned predictor   Comparator
G5  typed function-head system                 Comparator
```

Interpretation:

- G0–G2 success supports Field-embedded taxonomy-independent Dynamics;
- G3-only success means a generic external predictor supplied the capability;
- G4-only success means explicit Assembly state was required;
- G5-only success means typed human functional categories were required.

Comparators must not enter the Primary import graph.

## 9. Runtime invariants

1. Explicit Assembly state is forbidden in the Primary runtime.
2. Prediction, action, memory, reward, outcome, goal, role, and meaning relation types are forbidden.
3. Endogenous events are hypotheses, never external observations.
4. Positive learning requires registered external consistency; internal recurrence cannot confirm
   itself.
5. Observer/evaluator removal, renaming, or taxonomy permutation must leave runtime unchanged.
6. No privileged scalar reward or correct-action target enters the Primary run.
7. Internal pulses pass through ordinary threshold, inhibition, refractory, adaptation, and safety
   rules.
8. Generation remains bounded by depth, energy, lifetime, branch count, and proposal count.
9. Direct copies, fixed-delay echoes, pending queue replay, random pulses, and evaluator leakage must
   be excluded.
10. Relation re-entry must use existing anonymous state before any new persistent learned-state type
    is introduced.
11. Missing-middle counts as forward completion only before the later external cue.
12. Runtime ontology and observer taxonomy must be inventoried separately in every report.
13. New persistent learned-state categories require explicit protocol amendment.

## 10. Core scientific Gates

### Gate A — Runtime, observer, and taxonomy independence

- local deterministic reference;
- provenance and checkpoint integrity;
- Assembly and typed-functional field scan;
- Observer/evaluator present-versus-absent equality;
- evaluator category rename/permutation equality;
- no scalar reward or correct-action input;
- no comparator import on the Primary path;
- zero self-confirmation violations.

### Gate B — Endogenous origin and non-copy

- normally thresholded internal Spark without direct external supply at its target/time;
- copied-input, fixed-delay echo, pending queue, random-noise, and evaluator-target controls excluded;
- G3/G4/G5 absent from the Primary path;
- reproduced across preregistered worlds and perturbation seeds.

### Gate C — Persistent-state dependence

- identical current input under different valid prior states may produce different internal responses;
- identical full state reproduces identically;
- reset of the carrier state changes or removes the effect;
- transplant of the carrier transfers at least part of the effect or a distributed result is reported;
- no hidden evaluator context enters runtime.

### Gate D — Autonomous internal continuation

- an endogenous root changes later anonymous internal events under bounded silence;
- the chain exceeds pending-queue replay;
- safety budgets remain active;
- root/path suppression selectively changes downstream activity;
- result reproduces in held-out structures.

### Gate E — Untyped causal participation

- targeted root/path intervention changes the later anonymous trace more than matched random or sham;
- an effect reaches persistent state, boundary events, or the external stream;
- no typed functional head is involved;
- collateral damage is bounded.

### Gate F — Untyped relation stabilization

- an anonymous relation recurs across episodes and held-out perturbations;
- external consistency stabilizes it while internal-only recurrence does not;
- causal effect survives appropriate surface variation;
- frequency-only, readout-only, random-event, and no-endogenous controls are exceeded;
- no `relation_type` is stored.

### Gate G — External revision and causal re-entry

- external mismatch weakens or redirects stale anonymous links;
- external input remains authoritative;
- changed world contingencies revise relation dominance;
- the revised relation changes later normal-rule Field or boundary Dynamics;
- relation reset removes the changed behaviour;
- matched-unrelated relation state does not reproduce it;
- return of the old contingency restores both relation dominance and corresponding Dynamics;
- stable controls do not revise unnecessarily;
- no reward or correct-action target directs the effect.

### Gate H — Persistence locus and post-hoc equivalence

- reset/transplant identifies necessary, partially sufficient, distributed, or unresolved carriers;
- memory is not hidden in evaluator or comparator state;
- physically different trajectories are grouped only after matched causal signatures;
- observer grouping remains non-interfering;
- limitations of explicit G1/G2/consistency state are reported directly.

### Gate I — Confirmatory generalization and comparator interpretation

- code, metrics, thresholds, and exclusions are frozen before execution;
- at least five held-out world families and ten perturbation seeds are run;
- Level 1–3 evidence is reported per-world, per-seed, and in aggregate;
- no-endogenous, random-endogenous, readout-only, shuffled-state, G3, G4, and G5 controls run;
- strongest failures and counterexamples are preserved;
- comparator-only success is interpreted as a negative Primary result.

## 11. Primary experiment families

### E06-0 — Null, copy, echo, and typed-leak controls

External silence, random pulses, copied targets, fixed delays, pending queues, frequency-only paths,
forbidden typed fields, reward injection, and correct-action injection.

### E06-1 — Non-copy endogenous Field Spark

Hold current input fixed, vary valid prior state, and require an actual normally thresholded Field
Spark plus no-history and no-reinjection controls.

### E06-2 — Persistent-state dependence

Use identical current input under distinct histories. Reset and transplant candidate state components.

### E06-3 — Autonomous endogenous chain

After the root Spark, provide bounded silence and compare root suppression, local-path suppression,
matched random, sham, and queue-drained controls.

### E06-4 — Generic downstream influence

Compare the complete anonymous trace under `do(root present)` and `do(root suppressed)` before any
observer functional interpretation.

### E06-5 — Anonymous boundary coupling

Expose arbitrary outbound ports without names or correct targets. Test causal effects on later raw
external streams.

### E06-6 — External relation stabilization and reversal

Repeatedly expose anonymous lineages to later raw external consistency or contradiction. Measure
stabilization, internal-only no-growth, reversal, reacquisition, and stable controls.

### E06-7 — Relation re-entry

Use existing anonymous link state to generate category-free proposals through normal Field
reinjection. Compare:

- relation re-entry enabled;
- no re-entry;
- consistency reset;
- consistency transplant;
- shuffled relation state;
- matched unrelated link;
- internal-only relation exposure;
- reversal and return-to-old contingencies.

Measure actual later Field Sparks, boundary events, and state hashes rather than evaluator labels.

### E06-8 — Persistence-locus reset and transplant

Reset or transplant Field, threshold/adaptation, weight/delay, G1, G2, queue, consistency, and re-entry
components individually and jointly.

### E06-9 — Missing-middle and validity assays

Run forward missing-middle, prefix continuation, branching, omission, retrospective inference,
queue-drain, fixed-echo, and noise assays. Forward completion requires:

```text
created_at(C_endogenous) < arrival_at(D_external)
```

### E06-10 — Confirmatory held-out suite

Run frozen Level-1–3 worlds and comparators across preregistered world families and perturbation seeds.

### E06-11 — Observer and taxonomy adversarial suite

Remove evaluators, rename views, permute port descriptions, remove reward/action terminology, and
require identical runtime trace, queues, boundary events, updates, RNG state, and checkpoint.

### E06-12 — Physical-trajectory causal equivalence

Compare physically different lineages by complete causal signature under intervention and revision.
Do not merge them in runtime or infer equivalence from surface similarity alone.

## 17. Completion criteria

Positive completion requires Gates A–I and at least one successful G0/G1/G2 Primary route.

The strongest permitted future statement is:

> Under controlled pre-semantic conditions, a persistent Dynamic Field generated endogenous Sparks
> not directly supplied by current input. Without explicit Assembly or predeclared prediction,
> action, memory, reward, role, or meaning types, those Sparks causally altered later anonymous Field
> and boundary states; externally stabilized and revised anonymous relations re-entered later normal-
> rule Dynamics; and the effects reproduced across held-out worlds and perturbation seeds.

Negative completion is valid when all amended Primary experiments, persistence-locus analyses,
validity assays, G0–G5 comparisons, confirmatory runs, taxonomy audits, and strongest counterexamples
are completed and reported honestly.

v0.6 does not claim semantic understanding, human-like concepts, autonomous value formation, organs,
consciousness, AGI, biological equivalence, or physical energy superiority.
