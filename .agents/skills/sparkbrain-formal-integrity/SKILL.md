# FORMAL integrity workflow

Use only under fresh Evidence Analyst FORMAL authority.

1. Re-fetch the exact candidate identity, frozen protocol/package/source refs and authority.
2. Verify the identity has not already been consumed.
3. Verify exact binding, STARTED/no-clobber, matched privilege/resources and held-out/evaluator isolation.
4. Freeze prospectively specified metric/comparator/threshold/tolerance/protocol before outcome exposure.
5. Execute once.
6. Preserve raw result before reading/scoring when the protocol requires it.
7. Score only against the frozen contract.
8. Preserve immutable evidence and exact provenance.
9. Never rerun, retune, rescore, redispatch or repair the same consumed identity after outcome exposure.
10. If the result exposes a flaw, keep the historical result and create only a fresh independently authorized successor/revision where policy permits.

This skill cannot be invoked to rescue a failed or inconclusive consumed FORMAL object.
