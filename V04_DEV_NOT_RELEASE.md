# SparkBrain v0.4 development implementation

This branch adds a pre-semantic, event-driven temporal signal layer while preserving the v0.3/v0.3.2 semantic evidence and belief runtime.

The v0.4 reference models:

- timestamped local digital pulses;
- membrane-like accumulation and decay;
- refractory state and adaptation;
- signed recurrent propagation with conduction delays;
- local bursts, cascades, and repeated temporal assemblies;
- cascade-level Ignition;
- bounded STDP-like timing plasticity;
- temporal expectation / omission error pulses;
- minimal action/reward association;
- local JSON checkpointing and an offline raster visualizer.

This is a **development engineering layer**, not a public release and not evidence of semantic understanding, biological equivalence, concept/organ formation, energy efficiency, consciousness, or AGI.
