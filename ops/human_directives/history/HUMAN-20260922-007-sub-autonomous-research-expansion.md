# HUMAN-20260922-007 — SUB autonomous research expansion

Created: `2026-09-22 JST`  
Origin: explicit human approval

## Intent

SparkBrain SUB should no longer behave mainly as a passive secondary executor that returns `NO_COHERENT_MECHANISM_TARGET -> NO_OP` whenever Evidence Analyst has not already supplied a sufficiently mature mechanism target.

The human side wants SUB to act as a genuine second research worker whose job includes generating, shaping, and maturing the next scientific question before it is ready for MAIN.

The goal is not to manufacture activity. The goal is to reduce wasted SUB capacity while preserving scientific integrity and MAIN ownership.

## Role change

SUB should be treated as:

> **an independent secondary researcher responsible for finding and maturing research questions that are not yet on MAIN's critical path.**

SUB may still execute explicit Analyst sub lanes and normal Discovery work, but when no usable target exists it should actively search for one before returning NO_OP.

## Mandatory pre-NO_OP research scan

Before `NO_OP`, SUB should inspect, at minimum:

1. fresh-successor potential from recently terminalized SYSTEM and MECHANISM object families;
2. theory-backward questions tied to central SparkBrain goals;
3. unresolved phenomenon-first surfaces;
4. new residual questions exposed by Literature, Independent Audit, Methodology, Utility, or recent architecture/tooling work;
5. new observables, interventions, comparators, reductions, scaling regimes, or measurement surfaces that did not exist when an older object was terminalized.

SUB may return NO_OP only after this scan finds no safe, useful, nonduplicative bounded research direction.

## Question-formation Discovery

Introduce a noncanonical, NON_EVIDENTIARY mode:

`QUESTION_FORMATION_DISCOVERY`

This mode exists specifically for the 0->1 phase where a mature MECHANISM candidate does not yet exist.

A QUESTION_FORMATION_DISCOVERY run may:
- inspect the relevant stable/research surfaces;
- define a bounded phenomenon/question;
- identify candidate observables;
- identify one or more plausible ordinary reductions;
- formulate a provisional falsifier/discriminator;
- run a small synthetic/dev/read-only diagnostic where safe;
- create an exploratory branch when implementation is necessary;
- return a candidate seed or fresh-successor proposal to Evidence Analyst.

It does not count as an admitted canonical candidate, theory-backward quota success, PRE_FORMAL readiness, or scientific evidence.

A fully coherent mechanism-level question is therefore not required **before** starting QUESTION_FORMATION_DISCOVERY. The purpose of this mode is to determine whether such a coherent question can be formed.

## Fresh-successor exploration

SUB may independently explore whether a terminal object family supports a legitimate fresh successor.

This is allowed only when the prospective question is materially new, for example because of:
- a new observable;
- a new intervention;
- a new reduction/comparator;
- a new mechanism residual;
- a new measurement surface;
- a new tooling capability that changes identifiability.

SUB must not reopen or rewrite the terminal object itself.

Any fresh canonical successor still requires a new candidate ID and Evidence Analyst admission.

## Bounded Architecture-style exploration

SUB may perform bounded NON_EVIDENTIARY architecture-style diagnostics during Discovery when needed to determine whether a candidate seed is real and reachable.

This does not mean SUB can self-promote an object into canonical ARCHITECTURE_STUDY. Evidence Analyst retains classification/admission authority.

## Relationship with theory-backward supply

Keep the one-in-three theory-backward supply rule for actual autonomous scientific selections.

QUESTION_FORMATION_DISCOVERY is denominator-excluded until it matures into a real autonomous Discovery selection with a coherent mechanism-level question and explicit reduction/falsifier.

Therefore the new mode must not be used to game the theory-backward quota.

## Relationship with MAIN

SUB remains independent of MAIN critical path.

It must not:
- fix MAIN blockers merely because it is idle;
- work MAIN's active branch/object/identity;
- create a hidden dependency that MAIN must wait for;
- consume or alter FORMAL authority.

If a SUB-generated question becomes central/high-information enough for MAIN, SUB should hand it to Evidence Analyst for allocation rather than silently taking over MAIN responsibility.

## Relationship with Utility

Utility remains the cross-cutting implementation/tooling worker.

SUB should use Utility only for bounded complementary tasks outside SUB's selected scientific question. SUB must not offload its own research responsibility merely to stay active.

## Development iteration

Apply HUMAN-20260922-005.

Cycle 3 is reassessment, not automatic termination. Development iteration is allowed in Discovery/Architecture/PRE_FORMAL while preserving provenance and the FORMAL one-way floor.

## Hard floor

Unchanged:
- no rerun/retune/rescore of consumed FORMAL identities;
- no immutable/formal/sealed/evidence mutation;
- no evaluator/held-out leakage;
- no post-FORMAL rescue tuning;
- no same-object SYSTEM->MECHANISM rewrite;
- no fabricated novelty or quota gaming;
- no collision with active MAIN ownership.

## Expected output from SUB

Every autonomous no-target run should now report either:
- a selected bounded Discovery target;
- a QUESTION_FORMATION_DISCOVERY task/result;
- a fresh-successor candidate seed;
- or a justified NO_OP after documenting the pre-NO_OP scan.

Evidence Analyst retains canonical admission, claim ceiling, eligibility/readiness, and FORMAL authority.

## Required independent review

Control Brain and Evidence Analyst should independently evaluate this directive and may constrain it only for concrete collision, integrity, or low-information-gain risk.

The intended default is:

> **No target yet is a reason to search for a target, not automatically a reason to idle.**
