# SparkBrain Control Brain — Latest Strategic Handoff

Analysis time: 2026-09-15 18:55 JST

## Central theory

SparkBrain should currently be treated as a search for a persistent, pre-semantic dynamical cognition mechanism rather than a search for a novel neural-network layer. The strongest unresolved residual is **causal circulation**: an anonymous external consequence returns through the actual historical causal lineage, selectively changes local support/credit, and thereby changes later local competition without semantic/task labels or privileged global lookup.

A01 P2 development evidence is the first direct positive observation on that residual: preserved candidate-002 evidence supports selective world-to-local circulation at a shared root. This is important but not sufficient. It may still be ordinary explicit causal/eligibility memory expressed in SparkBrain vocabulary.

## Strongest evidence for the current theory

- A01 P2 development candidate-002: selective external match/contradiction changed only the causally addressed proposal and changed later shared-root competition while non-causal confidence and arrival timing remained fixed.
- CX01: strong explicit/contextual comparators share a formal failure frontier on rapid contingency-cycle, making fast closed-loop adaptation a legitimate unresolved target rather than a benchmark already solved by every comparator.
- RV02 diagnostics: eligibility-like state alone was insufficient when a usable causal-return opportunity was absent, supporting the distinction between “trace exists” and “causal loop closes.”

## Strongest evidence against broad SparkBrain novelty

- v0.5 anonymous assemblies remain compatible with known assembly / reservoir / temporal-memory families.
- v0.6/v0.6.1 showed explicit-state dominance and formally unsupported Primary behavior.
- RV01 R01-16 shows much of the supposedly special traversal effect is explained by learned connection weight; ordinary local plasticity should be preferred over mysterious Field explanations.
- A01 P2 has not yet survived carrier-locus, ambiguity, or strengthened reduction tests.

## What is already reduced or substantially demystified

- Anonymous temporal assemblies by themselves are not novel.
- Refractory/adaptation are not sufficient explanations for the important RV01 effect.

## Residual mechanism that remains genuinely unresolved

The narrow unresolved claim is:

`external consequence -> actual causal lineage -> selective anonymous local credit -> changed future local competition -> changed later interaction`

The crucial question is not whether this can be implemented. It is whether it survives strong state-locus and ambiguity tests and whether a minimal explicit/recurrent causal-memory null can reproduce the same causal dynamics with equal or lower privilege/state.
