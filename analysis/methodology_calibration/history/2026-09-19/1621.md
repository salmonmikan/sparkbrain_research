# SparkBrain Methodology Calibration Audit — 2026-09-19 16:21 JST

Overall classification: **`MIXED_CALIBRATION`**.

## Material change

This first calibration run finds that recent SparkBrain methodology had two distinct movements that should not be conflated:

- **FORMAL scientific standards tightened for mostly evidence-driven reasons**: C19-R2 supplies a concrete FSA reduction; NI01 exposes comparator world/regime-label privilege; PD01/H5 sharpen absent-signal versus mechanistic-reduction semantics; new causal-credit literature adds ordinary counterfactual-credit baselines and stronger-privilege ceilings.
- **Research allocation had become overconservative outside FORMAL claims**: `NO_HIGH_VALUE_FORMAL_OBJECT` propagated into repeated MAIN HOLD + SUB no-op despite architecture/testbed framing. A new live scheduler doctrine now prospectively splits `DISCOVERY`, `ARCHITECTURE_STUDY`, `PRE_FORMAL`, and `FORMAL`, separates claim types, and bounds exploration cycles. This is a sound correction that preserves the hard one-way integrity floor.

The latest durable Analyst/MAIN/SUB handoffs still show the previous HOLD/no-op regime, so the new funnel's effect is not yet demonstrated operationally.

## Core calibration result

The programme was **too conservative in research allocation, not too strict in formal scientific integrity**.

Keep:
- no rerun/retune/rescore of consumed identities;
- frozen/prospective protocol discipline;
- raw-before-score and preserve-before-read;
- exact source/package/runtime/input/identity binding;
- immutable evidence and no evaluator/target leakage;
- prospectively positive candidate-signal gate before strong mechanistic reduction language;
- equal-privilege comparator matching;
- a strict new-computational-principle novelty bar for that claim type.

Split or clarify:
- architecture/system/testbed research must not inherit the strongest novelty threshold;
- `NO_HIGH_VALUE_FORMAL_OBJECT` should stop FORMAL execution, not automatically all lower-layer research;
- stronger-privilege COMA/C3/replay/global actual-cause solvers should be recorded as functional ceilings unless privilege is actually matched, not automatic mechanistic reject gates;
- previous H1-H9 family coverage should prevent literal duplication, not be treated as blanket observable-level exhaustion;
- independent-motivation rules should prevent rescue of consumed outcomes, not forbid prospectively defined literature-seeded fresh Discovery.

The default ~3-cycle exploration budget is well calibrated as an anti-rescue / opportunity-cost control, provided exceptions are reasoned and no cycle tunes against formal held-out outcomes.

## PASS reachability

A new-principle PASS remains difficult but realistically specifiable:

`positive native signal -> fresh exact-bound prospective object -> matched equal-privilege comparators -> survive ordinary reductions -> fixed intervention/numeric falsifier -> one-way preserved evidence`.

PASS would become structurally unreachable if stronger-privilege replay/global-critic/counterfactual solvers were required as if they were equal-privilege comparators despite different information/action surfaces.

## Moving-goalpost assessment

`LOW_RETROACTIVE_RISK`.

Important tightening has remained prospective and consumed evidence has stayed immutable. New literature and audit results should continue to calibrate future objects only; they must not be treated as retroactive preregistered comparators for past experiments.
